readme_content = """# Task API

A lightweight, production-ready Task Management RESTful API built with **FastAPI**. Designed for high-performance asynchronous request handling and automated interactive API documentation.
 
---

## Installation &  Running

Ensure you have Python 3.8+ installed, then run the following command to install dependencies and start the server:

```bash
pip install fastapi uvicorn pydantic && uvicorn main:app --reload

```

The application will be accessible at `http://127.0.0.1:8000`.

---

## API Endpoints

| Method | Endpoint | Description | Status Codes |
| --- | --- | --- | --- |
| **GET** | `/` | Returns API metadata and available endpoints. | `200 OK` |
| **GET** | `/health` | Returns server operational status. | `200 OK` |
| **GET** | `/tasks` | Retrieves the complete list of tasks. | `200 OK` |
| **GET** | `/task/{task_id}` | Retrieves a specific task by its unique ID. | `200 OK`, `404 Not Found` |
| **POST** | `/tasks` | Creates a new task item. | `201 Created`, `400 Bad Request` |
| **PUT** | `/tasks/{id}` | Updates an existing task's title. | `200 OK`, `404 Not Found` |
| **DELETE** | `/tasks/{id}` | Removes a task by its ID. | `200 OK`, `404 Not Found` |

---

## Example Request (`curl -i`)

Executing a request to retrieve all tasks:

```bash
curl -i [http://127.0.0.1:8000/tasks](http://127.0.0.1:8000/tasks)
```
